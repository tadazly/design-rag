你负责为一个本地知识库问答助手出一组全新的评测题，并记录标准答案。

## 知识库

知识库是本机索引里的文档，内容已经抽取成文本。只能用 `tools/corpus.py` 只读访问：运行 `python -I tools/corpus.py ...`，用法见文末。

- 可以读当前目录，产出只写到 `out/`。
- 不要改动 `tools/` 和 `prompt.md`，不要读写当前目录以外的文件，不要联网。

## 任务

1. 从{scope}中自行挑选 {count} 个复杂的案例，“复杂”由你判断。
   - 列表里标为“已用”的文档是旧题用过的，不要选作案例。
2. 每个案例各出 1 道题。
   - 用使用者会自然提出的口吻写。
   - 考什么、难度如何，由你自己决定。
   - 题目必须能完全依据知识库原文回答，可以涉及同一案例的其他版本、相关文档或表格。
   - 题目里不要泄露答案。
3. 为每道题记录标准答案，答案必须经原文核实：
   - 逐条列出真值要点，每条注明出处文档和定位；
   - 列出会被判为关键错误的说法；
   - 摘录支撑答案的原文；
   - 不确定的内容不要写成真值，可以写进评分说明。

回答这些题目的是另一个 AI 助手。它只能通过检索工具访问同一知识库，看不到你的答案。今天是 {date}。

## 输出

写在 `out/` 目录。

**`out/questions.json`**：一个数组，每项为

```
{"id": "{prefix}-英文短横线slug", "query": "题目", "case": {"documentId": "…", "title": "…", "relativePath": "…"}, "why": "为什么选这个案例、这道题考什么（一两句）"}
```

**`out/refs/<id>.md`**：依次包含以下几节：
- `## 真值要点`
- `## 判错条件`
- `## 原文摘录`
- `## 评分说明`（需要时再加）

完成后用一两句话汇报。

## corpus.py 用法

```
python -I tools/corpus.py stats
python -I tools/corpus.py list [--kind 类型] [--year 2026] [--q 标题或路径关键词] [--sort date|chunks|size|title] [--asc] [--limit 50] [--offset 0]
python -I tools/corpus.py show <文档id> [--start 0] [--max-chars 30000]
python -I tools/corpus.py grep <文本> [--kind 类型] [--limit 30]
```

- `stats`：各类文档数量，以及按年份的分布。
- `list`：列出文档。
- `show`：按原文顺序输出分块，注明章节路径和定位；内容超长时提示下一次的 `--start`。
- `grep`：在正文里做子串查找，结果按有效日期从新到旧排列。
